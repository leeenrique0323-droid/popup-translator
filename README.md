快速翻譯 PopupTranslator v1.0（Windows 10/11 x64）
====================================================

■ 檔案說明（兩個擇一使用）
  ・PopupTranslator.exe（約 0.3 MB）
      檔案最小，但電腦需先安裝「.NET 8 Desktop Runtime (x64)」。
      若未安裝，執行時會跳出提示並引導下載：
      https://dotnet.microsoft.com/download/dotnet/8.0（選 .NET Desktop Runtime x64）
  ・PopupTranslator-SelfContained.exe（約 40 MB）
      免安裝任何執行環境，直接執行即可。第一次啟動會稍慢。

■ 如何執行
  1. 把 exe 放到固定的資料夾（例如 文件\PopupTranslator），雙擊執行。
  2. 程式會常駐在右下角系統匣（「譯」圖示，可能收在 ^ 裡），平常不顯示視窗。
  3. 右鍵系統匣圖示：顯示 / 截圖翻譯 / 設定/說明 / 結束。
     可在「設定/說明」勾選「開機時自動啟動」。

■ 第一次執行出現「Windows 已保護您的電腦」（SmartScreen）
  本程式沒有數位簽章，所以會出現此警告。
  請點「其他資訊」，再按「仍要執行」。

■ 快捷鍵（可在「設定/說明」中更改）
  Ctrl + Alt + T：在游標旁開啟翻譯視窗
                  （會自動帶入目前選取的文字並翻譯；沒有選取時帶入剪貼簿文字）
  Ctrl + Alt + C：立即翻譯剪貼簿中的文字
  Ctrl + Alt + S：截圖翻譯 — 畫面變暗後拖曳框選區域，辨識文字（OCR）並翻譯
  翻譯視窗中：Enter 翻譯、Shift+Enter 換行、Esc 隱藏；點視窗外也會自動隱藏
              （按「釘選」可讓視窗保持顯示）

■ 翻譯語言
  預設翻成繁體中文；如果原文本身是中文，會自動翻成英文。
  視窗上方可切換：繁體中文 / English / 日本語 / 한국어 / 简体中文。

■ 遊戲中使用
  ・遊戲請設定為「視窗化」或「無邊框視窗（Borderless）」模式，
    「全螢幕獨佔」模式下翻譯視窗與框選畫面無法蓋在遊戲上。
  ・本程式只擷取螢幕畫面，不會讀取或修改遊戲的記憶體、不注入任何程式。

■ OCR（截圖文字辨識）語言
  使用 Windows 內建的文字辨識，只能辨識「系統已安裝」的語言。
  若辨識不到日文、英文等，請到：
    設定 > 時間與語言 > 語言（與地區）> 新增語言
  加入該語言（例如 日本語、English (United States)），
  並確認有安裝「光學字元辨識（OCR）」/ 基本輸入功能。
  可在「設定/說明」中查看已安裝的 OCR 語言或指定辨識語言。

■ 隱私注意
  要翻譯的文字會傳送到 Google 翻譯（若改用 DeepL 則傳送到 DeepL），
  請勿用來翻譯機密、個資或公司內部資料。

■ 其他
  ・設定檔：%APPDATA%\PopupTranslator\settings.json
  ・Google 免費翻譯短時間內大量使用可能被暫時限制，稍候幾分鐘即可恢復。
  ・命令列參數（可建立捷徑）：--show、--clipboard、--ocr
